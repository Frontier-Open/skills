# 封面文案

封面只有一个任务：让人在信息流里停下来。所有文案都为「一眼看懂 + 想点开」服务。

## 通用规则

- 3-4 行，每行 5-9 字，一行一个意思，不要写完整长句。
- 只留一个高亮词，落在收益或数字上：`3分钟`、`五万粉丝`、`省下`、`神器`。
- 说人话，不说品牌话。「我用三个月」比「本方案历时三个月」有效。
- 数字优先：具体数字（`5个工具`、`2小时`、`99%`）比形容词可信。
- 角标是社会证明，4-5 字：`亲测有效`、`听劝版`、`新手友好`、`免费工具`、`超好用`。

## 常用钩子

- **结果前置**：我用一个晚上 / 把想法 / 做成第一期
- **痛点共鸣**：设备买了很多 / 还是没有 / 录第一期
- **反常识**：别先买设备 / 先录十分钟
- **清单式**：这3个动作 / 让内容 / 更快上线
- **提问式**：为什么你的内容总发不出去？/ 因为没有下一步
- **身份锚定**：一个人做内容 / 也能 / 稳定发布

## 各版式的文案形状

**思考型** — 左对齐陈述句，像一句写在纸上的结论。适合「我做了什么 + 得到什么结果」。
高亮词放在第一或第三行，避免落在最后一行导致视觉断尾。

**对话框型** — 卡片里放一问一答或一句劝告，`subText` 补一句支撑（`看完就能直接用`、`小白也能秒变设计师`）。
主文案不超过 3 行，卡片一满就失去对话感。

**情绪型** — 三行递进的情绪流水账，前两行铺垫、第三行落点，不用高亮词，靠角标点出身份（`打工人日常`、`真实体验`）。

**引用型** — 一句完整的话拆成 2 行，句子要能独立成立、离开上下文也读得懂。副标题写出处或落款
（`—— 写在第 47 次重开之后`），破折号开头能让它立刻读起来像引文。高亮是下划线，标在句子的转折词上。

**便签型** — 首行是标题，后面几行是条目，全部左对齐，横线会自动落在每行字下面。适合待办、周计划、
备忘。行数 3-5 行最好看，太少显得纸是空的。

**清单型** — 副标题是承诺（`封面别再犯的三个错`），主文案是条目，条目自动编号。条目必须句式平行、
字数接近（`先说结果 / 再说代价 / 最后给方法`），长短不齐会立刻显得没设计过。承诺里的数字要和条目数一致。

## 一键生成

`scripts/cover.js` 里的 `SEEDS` 保留了原站「🎲 一键生成」的词库（标题、高亮词、角标、表情），
`randomSeed()` 从中抽样。它适合快速起草或做风格样例，正式产出仍应按上面的钩子重写文案。
